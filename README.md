# RID 固定式侦测设备 · 网页产品演示

一台固定式无人机 RID 侦测设备的网页产品演示：可交互拆解 + 分镜讲解动画。
纯静态单文件（Three.js 已内联，含三套大疆实体模型与神经网络语音），离线双击即可运行。

## 在线体验

<https://ddjjnk.github.io/low-altitude-defense/>

## 两种玩法

**拆解视图** — 鼠标左键旋转、滚轮缩放、右键平移。
点左侧部件清单任意一项，镜头会推到该零件正面；点零件本身也能选中，再点一次退回总览。

**侦测演示** — 点底部「侦测演示」，按分镜走完一条完整链路：

| 分镜 | 内容 |
| --- | --- |
| 设备待机 | 固定布设，无源侦听，不主动发射探测信号 |
| 系统上电 | 合闸、天线阵列自检 |
| 目标广播 | 无人机迎面飞来，持续广播 Remote ID 报文 |
| 天线接收 | 天线阵列被动截获 2.4G / 5.8G 广播 |
| 芯片解析 | RID 解析 → 北斗授时 → 主控关联 → 4G 封装 |
| 4G 回传 | 航迹加密回传云端 |
| 平台汇聚 | 多站组网、航迹成图 |

演示中「拆解视图」会被锁住，退出演示自动恢复。

## 技术要点

- 三套大疆机型网格（Mavic 3 Pro / Air 3S / Mini 4 Pro）离线抽稀到 1～2 万面后以 int16 + base64 内嵌
- 机身涂装没有 UV，按模型局部坐标在片元着色器分区上色（上盖 / 侧身 / 机臂 / 云台 / 桨叶）
- 讲解词由 Edge 神经网络语音「晓晓」合成，音频内嵌，声画时长在运行时自动对齐
- GB 46860 风格的 20 位 UAS-ID（4 位厂商码 + 4 位产品型号码 + 12 位序列号）
